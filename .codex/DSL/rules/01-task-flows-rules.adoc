== 规范说明

本文档是 Task 执行流程的约束摘要，不重复维护 Flow 正文。

SSOT 说明：

- 执行步骤顺序的唯一权威为 `.codex/DSL/flows/task-execution-flow.adoc`。
- 状态机与门禁的唯一权威为 `.codex/DSL/rules/04-state-and-gates-rules.adoc`。
- 核心对象最小契约见 `.codex/DSL/rules/04-core-model-rules.adoc`。

适用范围：

- 适用对象：所有基于 Task / Sub Task 的执行流程
- 适用范围：代码实现 / 重构 / 文档生成 / DSL 驱动任务
- 约束强度：必须遵守，不得跳过或弱化

== 流程摘要约束

- 进入前置：任务/子任务处于 `READY`，依赖已满足。
- 执行顺序：必须遵循 `ANALYZE -> PLAN -> EXECUTE -> VALIDATE -> REPORT`。
- 计划约束：`PLAN` 必须输出文件清单与每个文件的修改目标。
- 执行约束：`EXECUTE` 仅允许修改 `PLAN` 中声明的文件。
- 校验约束：`VALIDATE` 必须显式给出“通过/不通过”与违规项。
- 报告约束：`REPORT` 必须输出变更清单、验证证据与风险说明。

== 停止条件摘要

出现以下任一条件必须停止：

- DSL 存在歧义且无法裁决
- 修改范围超出任务边界
- 目标不明确或关键依赖缺失
- 违反强约束且无法在当前轮修复

停止时必须输出：

- 停止原因
- 已完成步骤
- 未进入步骤
