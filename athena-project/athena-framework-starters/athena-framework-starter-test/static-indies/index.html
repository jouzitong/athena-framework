Athena Test Studio

核心链路

版本 -> 流程 -> 节点 -> 执行 -> 进度

这个原型直接模拟测试平台的主业务流程，而不是单纯做展示页面。

参数能力

  • 手动输入启动参数
  • 自动参数生成：随机数
  • 自动参数生成：时间戳
  • 自动参数生成：UUID

业务原型

围绕“测试版本化执行”设计的完整工作台

用户先创建版本，再在版本下维护测试流程和测试节点。 启动测试任务时可手动输入参数，或者让系统自动生成动态参数。 执行中可看到测试进度、节点状态、执行记录和调度进程。

当前业务流

操作链路

01
创建测试版本

定义业务基线版本，例如 trade-regression v2026.06.29。

02
绑定测试流程

在版本下创建一个或多个测试流程，按业务链路拆分场景。

03
配置测试节点

每个流程维护 HTTP / WS / ASSERT 节点，节点支持动态参数。

04
启动测试任务

手动输入或自动生成参数，然后触发测试执行。

05
查看进度与结果

查看执行计划、实时进度、日志、节点结果和调度状态。
